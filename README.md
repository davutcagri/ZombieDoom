# ZombieDoom

ZombieDoom is a small 2D zombie game I made with Java.

I built it mainly to practice object-oriented programming and basic game development concepts such as movement, collision detection, enemy behavior and game state management.

The game includes player movement, shooting, zombies, health and score systems.

## Running

Compile and run the project with Java.

```bash
javac *.java
java Main
```

The project is still fairly simple and I may add more enemy types, weapons and gameplay improvements later.
